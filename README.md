# Wego Informatics

This repository contains PDF materials, source code and other educational resources created by Jhe-An Lee for the
Informatics Club at Taipei Wego Private Senior High School during the 2024 and 2025 academic years (113, 114 學年度).

The course is designed for beginners with little or no prior knowledge of C++, general programming or competitive
programming. All source code is written in a competitive programming style.

Note: This repository does not contain every resource made available to students. Materials created by other students,
as well as materials from previous or subsequent years, are not included.

## Files

Source files and PDF materials are organised into units. Each unit contains the relevant materials and C++ source code
used for demonstrations. Some units also include coding exercises and sample solutions.

The `contests` directory contains validator, checker, solution and generator files used
for [Codeforces Polygon contests](https://polygon.codeforces.com)
